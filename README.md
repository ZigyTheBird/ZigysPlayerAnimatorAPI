# Zigy's Player Animator API

Zigy's Player Animator API is a library mod that helps you play player animations.  
You can play animations from both server and client side. (The mod automatically sends a packet to the client to play animations)  
You may also play animations using a server side command.  

Use the [GitHub wiki](https://github.com/ZigyTheBird/ZigysPlayerAnimatorAPI/wiki/Getting-Started) to see all the features of the mod and get started.
